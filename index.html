Forward kinematics in motion

A small robot arm follows a looping finite-state-machine choreography, with every link pose drawn from the runtime’s /xform_world output.

Robot and choreography

The robot is a custom five-link arm with shoulder, elbow, and wrist joints. The finite state machine moves it from a neutral home pose to a reach, then to a wave pose, and returns home before repeating.

How it is rendered

The viewer is an external Python TCP/JSON client. It subscribes to /xform_world, reads each link’s column-major 4×4 matrix, and draws links and local axes on a canvas.

The viewer source and run instructions are included in the fk_viewer.py.
